# 中介服务申请与记录

本次新增人工中介服务申请管理，不接入在线收款、退款或自动放款。费率沿用交易指南：0.68%，每笔最低6.80元。申请金额和费用是申请时的预估；最终交易总价、费用承担方、取消、验收、争议和放款条件仍须共同确认。

## 用户入口

- 龟集市首页：申请中介、我的申请；“双方已谈好”入口支持不关联平台商品的申请。
- 商品详情：申请中介服务，带入商品、品种和金额；服务端保存当时商品快照，商品下架后申请仍可查询。
- 空间：我的中介申请。
- 详情展示申请号、联系信息、费用、处理历史，可复制申请信息或微信号；记录不依赖剪贴板保存。
- 仅待受理的申请可以自行撤回；已受理后联系客服协商。

## 管理员入口

空间 → 全部中介申请，或运营中心 → 查看全部中介申请。支持状态筛选、申请号/商品/申请人搜索、分页、详情和处理说明。

状态：待受理 → 已受理 → 服务跟进中 → 服务已完成。处理中也可按实际情况关闭申请；状态变更必须填写用户可见说明，保留历史与管理员审计。同一记录使用版本号防止旧页面覆盖新处理结果。

用户登录后只可读取自己的申请，管理员鉴权由服务端完成，客户端传入管理标记不能获得权限。私人记录不写入本地公共列表缓存。注销账号时清除对应的申请记录；新注册同手机号不会取得旧账号申请的所有权。

## API 与存储

POST `/api/mediation/create`、`list`、`detail`、`withdraw`、`update`，均使用现有手机号与登录令牌鉴权。`list` 的 `scope=all` 与 `update` 仅管理员可调用。普通申请人只能查询/撤回自己拥有的记录。

新增根集合 `mediationApplications`，兼容现有 JSON、MySQL 整站模式及分记录模式，不覆盖用户档案或交易数据。创建使用账号内幂等请求标识；金额按分保存，服务费由服务器计算。成功响应等待数据库确认保存。

提交申请不增加商品“想要”计数。历史“想要”仍包含联系卖家等动作，不能当作申请人数。管理员列表的总数以实际保存的申请为准。

## 更新与验证

必须将前端 `app.js`、`index.html`、`privacy.html`、`terms.html`、`assets/trade-guide.js`、`assets/mediation.js`、`assets/mediation.css` 和后端 `server/server.js`、`server/mediation-service.js` 一起更新。服务器需重启 API 才会启用新接口；保留现有环境配置、数据库、上传目录及备份。手机 App 还需重新打包安装，新接口不会让旧安装包自动出现入口。

此改动已加入 iOS 1.2.1（141）源文件清单和 `check:mobile` 检查。执行 `scripts/upload-ios-141.sh` 后会验证、提交并推送本次改动，再自动复制并保存与该提交绑定的服务器接口安装命令。安装命令只补入 API，不替换网站 HTML；手机端入口随新安装包更新。网站如需同步展示入口，应另外按前面的前端文件清单更新。

验证命令：

```powershell
node scripts/test-mediation-applications.cjs
node scripts/test-mediation-applications-ui.cjs
$env:BROWSER_ENGINE='webkit'
node scripts/test-mediation-applications-ui.cjs
```

API 检查使用隔离目录和虚构账号。SQL 检查使用现有测试驱动验证延迟提交、失败回滚及重启恢复，并非真实生产 MySQL 压测；浏览器检查也不等同于手机原生设备测试。
