# iOS 1.1.6（131）启动广告与更新说明

日期：2026-10-08。版本号保持 1.1.6，主应用、通知扩展和网页构建号统一为 131。

日常养护标签顺序调整为「养护 → 温度提醒 → 提醒」，点击行为保持对应各自页面。

新增版本更新内容弹窗。启动广告结束或点击跳过后，展示本版本新增的温度提醒和提醒设置优化；点击「我知道了」或关闭后，本机同一版本不再自动展示。按版本号记录而非构建号，后续同版本测试构建不会重复提示。当天广告已显示过时，更新内容可直接显示；点击广告打开交易指南时，等待指南关闭后显示。隐私同意及强制更新弹窗优先，推送和分享跳转取消本次更新说明而不记为已读。

启动交易广告在每台设备上按北京时间自然日最多自动展示一次，实际显示时保存当天标记。跳过、自动关闭、同一天重新启动或从后台返回均不重复展示。跨日后的首次打开可再次显示。广告被推送跳转或深层链接取消、应用不可见或交易指南已打开时，不消耗当天次数。主动打开交易指南可照常使用。

标记保存在本机，与登录账号无关；本机存储不可用时仍通过内存限制当前运行期间的当天次数。清除应用数据或重装会清除本机记录。
