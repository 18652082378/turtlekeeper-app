# 软件复查：2026-09-26

本轮在本地现有工作区上检查并修复问题，保留此前已完成的界面与功能改动。没有部署正式服务器，也没有重新发布手机安装包。

## 已修复

1. **养护记录与待办状态不一致。** 删除完成记录、修改记录日期或再次记录后，按剩余关联记录重新计算提醒完成状态。删除最后一条完成记录会恢复待办；同一提醒仍有其他完成记录时，不会误恢复。
2. **档案编辑返回时丢失编辑上下文。** 从编辑页进入同步页等子页面，再返回时恢复选中的档案、编辑模式、照片及未保存表单；已经保存的成长表单不会被当作旧草稿恢复。
3. **成长提醒无法通过“无变化”检查完成。** 从待办进入并明确保存时，即使体重、背甲长、健康状态未变化，也记录本次检查并安排下一次提醒。批次成长待办在整批更新后也会调整提醒日期。
4. **成长时间线跨日显示错误。** 使用软件统一的中国日期格式，避免直接截取 UTC 时间而显示成前一天。
5. **历史品种筛选遗漏。** 同一只龟修改品种后，旧记录仍能通过当时的品种名筛选；关联乌龟选项和图片选择器采用同一历史记录来源。
6. **部分用户文字被解释为 HTML。** 档案名称、档案备注、提醒标题和备注、操作日志以及账本详情标题按文本转义，保留引号、尖括号等原文，避免破坏布局或插入页面元素。
