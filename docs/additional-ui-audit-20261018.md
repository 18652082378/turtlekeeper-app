# 追加界面与交互检查（2026-10-18）

在发布商品窄屏修复后，继续检查其他表单的原生控件固有宽度、可选字段、弹窗、照片选择、批次账本、页面返回和数据保留。所有测试使用独立浏览器及合成数据，API请求被拦截或指向独立本地测试服务；未访问生产用户数据。

## 发现并修复

1. 提醒表单星期按钮固定七列、每个圆形固定42像素，280/320/390宽度下出现重叠和超出网格。现在按钮保持44×44像素，440宽度及以下排列为4＋3，两行均在卡片内；较宽界面保留一行。新增边界检查、七个星期的勾选/取消验证和未保存提醒数据不变性验证。
2. 同一表单的“取消”在窄屏可能分成两行。为标题保留可收缩空间，取消按钮保持单行和至少44像素点击面积。
3. 成长页新增“查看全部更新”后，旧模块测试的全局选择器同时匹配筛选栏和空页面按钮。这是测试定位歧义。已精确定位筛选栏，并分别点击两个入口，验证105条成长数据分页、重置窗口及数据完整性，未改变产品筛选行为。
4. 关联档案提醒的独立回归测试仍模拟旧的苹果推送配置接口，未跟进安卓接入后的统一配置接口。已更新测试模拟，重新验证客户端/服务器的失效关联排除、账号隔离、发送去重与业务数据保留；未修改服务器业务代码。

共享CSS修复位于`assets/daily-workspace.css`，两端打包资源已同步。版本号未修改。
