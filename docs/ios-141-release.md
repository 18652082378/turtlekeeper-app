# iOS 1.2.1（141）

主 App 与通知扩展的所有 Debug/Release 构建号统一为141，营销版本、配置与包版本统一为1.2.1。未更改安卓版本号或现有强制更新策略。

## 本次更新

- 新增人工中介申请：商品详情带入商品信息，也可在双方已经谈好后独立申请。
- 空间增加“我的中介申请”，查询申请号、商品信息、预计服务费、处理进度和说明；待受理申请可撤回。
- 管理员可查看、搜索、筛选全部申请，并记录用户可见的处理说明和状态历史。
- 完善重复提交、回执丢失重试、账号隔离、迟到响应和未保存说明的保护。

费用沿用0.68%、每笔最低6.80元。申请进度管理不自动收款、退款或放款。

## 电脑上传

在 Git Bash 执行：

```bash
bash "C:/Users/Administrator/.codex/worktrees/e76e/turtlekeeper-app/scripts/upload-ios-141.sh"
```

脚本先验证1.2.1（141）配置、发布清单、双平台检查、原生手势检查、更新策略及更新说明，再仅暂存 `scripts/ios-141-changes.txt` 中本次改动。其他未提交的工作保留。推送只允许快进，不会强制覆盖远端 main。

完成后，GitHub main 的提交号须与脚本最后确认的提交号一致。脚本会自动复制服务器接口更新命令，并保存为 `output/update-mediation-141.sh`。

## 服务器与 TestFlight

1. 在已经登录的阿里云 **Shell** 粘贴自动复制的服务器命令。命令固定到本次提交，使用多个下载源和SHA256校验，无需输入提交号或服务器密码。
2. 安装器检查现有服务器函数与PM2目标，私下备份源文件，只补入中介接口及记录存储兼容字段；重启后检查账号鉴权、中介接口鉴权和 iOS／安卓／网页更新策略。失败时恢复旧API逻辑，并保留申请集合兼容处理，避免回滚源代码丢失申请记录。数据库、上传和环境文件不回滚。
3. 看到 `SUCCESS: mediation application API installed and verified` 后，在 Codemagic 从最新 main 启动 **iOS TestFlight** 构建。已失败的旧构建不会包含新代码。
4. 等待云端编译、签名与TestFlight处理。Windows上的源码和浏览器检查不等同于已生成签名IPA。

服务器命令不替换网站HTML。新手机安装包携带申请页面；如果要让线上浏览器也看到新入口，需要另行同步前端资源。
