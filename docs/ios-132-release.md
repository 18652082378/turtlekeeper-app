# iOS 1.1.7（132）全模块体验优化

日期：2026-10-08。主应用、通知扩展、网页配置、npm 包和锁文件版本统一为 1.1.7，构建号 132。当前在本地源码完成，需上传 Git 后由 Codemagic 编译签名。

## 用户可见变化

- 关联档案不存在时，成长提醒不再进入今日待办或提醒列表；服务器推送同步增加档案存在检查。普通未关联档案的养护提醒保留，详见 orphan-reminders.md。

- 登录页增加“忘记密码？”，通过注册手机号接收短信验证码重置密码，重置后旧会话失效、原有记录保留。功能需要先部署专用服务器补丁，详见 password-recovery.md。

- 所有普通内容页统一宽屏阅读宽度及紧凑标题区，聊天页保留原有滚动、键盘与手势坐标机制。每个路由均进入实际客户端的界面检查。
- 搜索框聚焦时加深整个圆角外圈为绿色，不再给内部输入框添加方形轮廓；键盘聚焦仍有明确提示。
- 龟集市与龟友圈点击搜索后进入独立搜索页，显示带图片的推荐品种和历史搜索。推荐参考在养档案、常用品种、已加载的收藏/浏览商品和近期搜索，初次使用展示图鉴品种；不虚构热度数字。
- 独立搜索页的输入框、清除和搜索按钮固定在标题栏下方，跟随 iPhone 顶部安全区；历史、推荐与结果在下方滚动。
- 龟集市和龟友圈主页的搜索入口同样固定在各自标题栏下方，上下滑动商品或帖子时仍可直接进入搜索；列表顶部预留空间，避免遮挡首项内容。
- 商品搜索结果移除“龟集市”标题栏，搜索框直接置于顶部安全区下；搜索框旁的返回按钮可退出关键词搜索，保留原有筛选条件。
- 历史只记录确认搜索的关键词，最近优先、去重、最多 12 条；按账号和模块分别保存在本机，支持清空。中文输入未确认时不执行搜索，账号/会话切换和离开页面会隔离过期请求。商品搜索沿用现有集市结果，帖子结果可进入详情并返回原搜索页。
- 看板压缩统计和四个常用入口，减少进入档案前的滚动距离。档案详情移除重复名称和状态块，照片可点击放大，体重与背甲数据进入首屏；有效的 0 值不再被当成缺失数据。
- 成长列表每次展示 40 份档案，继续查看可完整获取后续记录，筛选切换重置显示数量；全部原有时间轴保留。按母龟分组繁殖记录改用原数组追加，避免每次复制整个分组。
- 龟友圈发帖区压缩为标题、发帖按钮和三个快捷入口；消息列表增加统一边距和边框，活动摘要更紧凑；聊天缓存、删除、发送及原生侧滑逻辑沿用并回归。
- 集市商品照片与文字共用卡片边框。搜索或筛选无结果时提供清除筛选；本地模式保留已有商品数据，云端模式重建查询。我的空间将常用入口放在页面颜色设置之前。
- 品种页为字母索引预留宽度，索引在可滚动侧栏中完整可达，不遮挡搜索与品种行。照片、名称与选择按钮单行对齐。
- 修复高级报表结余卡浅色文字不可见的问题，核对浅深主题金额文字对比度。团队面板和导航减少留白；账户、同步、反馈、日志、规则及管理页沿用共同标题、控件和宽屏布局。
- 养护页取消占据大块空间的介绍卡与重复加号。标题旁可查看保存状态，下方直接提供喂食、换水和手动记录入口。
- 喂食方案与筛选并排，展开任一项时使用完整宽度；所有筛选条件和方案功能保留。
- 历史按日期归组，同日记录共用列表边框。没有关联乌龟、龟池或备注时，不渲染空的正文区域和“未关联龟池”占位。
- 每条养护记录右上角的“•••”提供编辑、删除。删除仍需确认；再次记录喂食保留日期更新、原有备注与关联档案，旧按钮的重复点击不额外写入。
- 养护提醒将时间、重复周期、具体星期和通知关闭状态分开显示；调整、移除放入“更多”。缺失历史操作时间不再显示“上次操作 -”。
- 账本减少顶部介绍与汇总留白，四个记账入口与五个记录类型排列更整齐。龟池及繁殖页的标题和新增入口采用紧凑布局。以上工作页面的宽屏内容限制为 1000px 并居中，不改变原生页面、底栏和手势返回的坐标机制。
- 养护标签支持方向键、Home、End；记录菜单可通过 Escape 关闭，焦点回到触发按钮。切换焦点、点击外部、打开另一条菜单或改变视口会关闭旧菜单。靠近底栏的菜单向上展开。
- 1.1.7 更新说明列出此次可见改动，仍在启动广告之后显示，同一版本确认后不重复；不包含启动广告频次的宣传条目。

## App Store 更新说明

优化看板、档案、养护、账本、繁殖、消息和个人空间布局，让常用操作更直接，信息展示更整齐。

养护记录按日期归组，提醒时间、重复周期和通知状态更清晰。成长记录分批展示，可继续查看完整历史。

优化龟友圈发帖入口、集市筛选、品种导航及报表显示，改善手机、宽屏和深色模式体验。

新增独立搜索页，可查看历史搜索与推荐品种，让查找商品和帖子更方便。
