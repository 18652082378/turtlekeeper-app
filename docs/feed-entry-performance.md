# 龟集市与龟友圈进入速度

本次优化针对等待首屏、新作品出现慢和大账号切换页面卡顿。

- 市场列表不再等待未生成的缩略图，已有缩略图立即复用；新缩略图在现有有界队列中生成，原图始终保留为后备。
- 龟友圈新增可选 feedOnly 请求，只处理当前页帖子和评论，不再为展示十篇帖子处理所有帖子的评论、会话列表和个人统计。旧客户端请求保持原协议。
- 龟友圈列表使用已生成的缩略图，点开仍查看原图，缩略图失败可自动退回原图。
- 进入页面先展示已有内容；市场缓存超过约十秒时在后台重新检查首页，快速切回和详情返回保留已加载的排序与分页。发现新内容时先显示点击提示；用户接受后，新推荐响应连同对应排序会话、分页游标一起替换。
- 切换底部页面不再序列化整个账号。普通列表读取完成后，先更新卡片，再合并保存本机缓存；该延后保存检查账号和登录会话，不能跨账号写入。
- 服务端返回账户变更、成交同步等业务数据时仍立即保存，数据库提交确认机制保持原样。

验证：test-feed-server-latency.cjs 使用未完成的图片任务证明列表不依赖图片处理；1200 篇测试帖子中只处理当前页十篇评论，内容、可见性和排序与旧协议一致。test-feed-client-latency.cjs 覆盖缓存先显示、后台请求占锁、登录切换、失败不循环重试、分页会话一致和保存时序。浏览器测试验证实际图片请求、原图预览、坏缩略图恢复以及分页与返回位置。

这些是代码路径及隔离测试的结果，不代表生产手机网络上的固定耗时或加速百分比。服务器优化需部署并重启后端；浏览器端需更新实际使用的版本资源，已安装 App 需重新打包更新。
