# 团队模块检查与修复 V10

## 已复现并修复

1. 自定义日期连续应用：前一次慢请求可能覆盖后一次查询，导致日期标题与金额不一致。现在只接受最新查询的结果。
2. 账号切换期间，旧账号请求失败可能清空新账号团队或显示错误保存提示。现在按账号会话隔离请求，并重置筛选状态。
3. 设置数据起始日期的成员，在售出审批通过、龟档案移出在养列表后，看不到已通过结果。现在根据可见账目判断已通过审批的可见性。
4. 已完成审批的内部命令可能包含原档案快照。接口现在仅返回审批显示需要的字段，避免旧日期历史随审批响应暴露。
5. 审批通过后的账目与审批命令曾共用对象，后续修改账目可能连带改变原审批内容。现在应用审批时复制命令，原审批与业务账目独立保存，并分别检查日期可见性。

## 测试范围

- 权限、邀请、成员移除、日期隔离、整窝隐藏、只读、审批、并发冲突和会员到期。
- 四类账目金额、原购入成本还原、CSV、月份/近一年/自定义/全部历史。
- 繁殖与孵化数量、加权比例、分批出壳、重复提交、历史关联。
- 延迟响应乱序、账号切换、失败表单重试及审批历史字段隔离。
- 浏览器 320/390/768/1100 宽度下 11 个模块与深色主题。
- 与已核对线上代码合并的本地 API/UI 回归，以及升级预检、应用、拒绝未知代码和失败回退。

测试运行在本地隔离环境，不代表已在生产服务器部署，也未进行苹果真实扣款或系统推送测试。

## 部署

这是累计升级包，包含 V9 及此前团队改进，可从已核对的 V6-full、V7、V8、V9 等版本直接升级，无需逐个上传旧包。

上传 `turtlekeeper-team-update-v10.tar.gz` 至服务器 `/tmp/` 后运行：

```bash
cd /tmp &&
tar -xzf turtlekeeper-team-update-v10.tar.gz &&
node /tmp/turtlekeeper-team-update-v10/deploy.cjs --check &&
node /tmp/turtlekeeper-team-update-v10/deploy.cjs --apply
```

出现 SUCCESS 后 Ctrl + Shift + R 刷新页面。无需删除旧包。安装器校验并备份代码，健康检查失败自动回退；不覆盖数据库、账号数据和环境配置。若预检提示文件版本不符，请保留报错，不要强制覆盖。
