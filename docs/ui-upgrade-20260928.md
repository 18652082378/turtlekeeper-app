# 全应用 UI 优化与验证（2026-09-28）

本次改动已写入本地代码并完成网页资源构建。版本号仍为 1.1.1；没有发布新的 App Store 包或部署正式服务器。截图、测试账号及测试记录均为本地虚构数据。

后续配色修正：根据用户截图反馈，深色模式改为中性黑灰，页面 `#121212`、卡片 `#1c1c1c`、内层信息块 `#262626`，文字与边框也取消绿色底调。看板、社区、空间、账本和团队的大块绿色背景统一调整；成长记录内外卡片采用相邻灰阶。绿色保留用于操作和必要的状态/数据提示。修正后重新运行 880 项本地界面检查通过，页面截图已更新。

## 已完成的改动

- 新增统一视觉层 `assets/ui-system.css`，覆盖看板、档案、养护、提醒、繁殖、龟池、账本、集市、社区、消息、账户、管理与团队页面。统一五种主题的文字、表面、边框、间距、按钮、输入框及弹窗样式。
- 看板入口改成紧凑的图标文字排列；压缩大块介绍区和装饰阴影，保留必要的数据层级。窄屏筛选分列，宽屏入口四列。
- 集市、社区、消息和远程列表首次加载采用骨架占位；加载、失败、成功空列表分别呈现。失败可重试；有缓存时保留已加载内容。
- 新增 `assets/ui-experience.js`，统一用户操作请求的忙碌提示与请求期间的重复提交拦截。后台同步、轮询和浏览统计不会占用用户按钮；成功及失败都会解除状态。写入接口使用明确清单，后续新增操作需要维护清单。
- 表单字段与标签关联，原生校验失败在字段旁显示说明，并保留已有帮助文字关联。移动端输入字号至少 16px，补上可见焦点、当前导航标识和状态播报。
- 弹窗约束键盘焦点、禁用背景交互，关闭后回到打开按钮；支持嵌套、隐藏后重开以及已有弹窗自身的关闭处理。强制更新和协议流程不会被公共代码直接移除。
- 允许双指缩放；新增动态效果遵守系统减少动态效果设置。
- 键盘视口事件按动画帧合并，避免同一帧重复更新。保留既有滚动恢复和固定导航定位机制。

## 先复现后修复的交互问题

1. 短距离滑动后停住仍使用残留速度，造成误返回。
2. 已向相反方向拖回，仍仅凭距离触发返回。
3. 横向滑动控件与页面边缘返回手势冲突。
4. 减少动态效果开启后，返回预览和部分弹窗仍执行动画；可见范围选择弹窗曾短暂超出视口。
5. 个人空间的手势使用过时根页面名单，有返回按钮却不能滑回消息页。
6. 图片、视频关闭后的防穿透逻辑吞掉下一次正常点击。现在新的按下或键盘操作会解除旧手势的拦截。

共享交互模块引入后的焦点恢复、隐藏弹窗、后台请求误占按钮、商品状态写入漏拦截等问题，也通过专项用例复现并在交付前修正。

## 成长记录排列调整

成长记录使用紧凑单层卡片：顶部照片、名称、品种与更新时间对齐；体重、背甲各占一列，以旧值→新值呈现，中间集中显示“相隔N天”和箭头，不再在两条历史记录之间另占一块。间隔对应前次到当前记录；首条有建档日期时沿用建档参照，无参照显示首次记录，缺失日期显示间隔未知。完整日期、更新次数、滑动提示和删除按钮收在底部。去掉重复说明和嵌套背景框，顶部只保留精简统计及筛选。常见记录卡高约157px，单次与多次记录高度相同。多次记录默认完整展示最新一次，仍可横向拖动查看历史。深色继续使用中性黑灰层级。

本次本地验证：全页面880场景通过；额外36组模拟成长记录截图覆盖320/390/520/1024px、浅深色、1/2/6次更新、长字段及5只乌龟的连续列表，无页面横向溢出、数值截断或底部操作重叠。实测拖动、时间轴点击不误进详情、删除确认取消后记录不变、点击名称进入档案。极端长数字在窄屏完整换行，原始数据不变。检查结果保存于 `output/ui-consistency/growth-compact-layout.json`。截图使用拦截的本地资源和合成记录；密度整页图通过固定高视口后重新渲染生成，避免浏览器fullPage截图引起横向位置变化。已重新构建 `www`；未验证正式版或真机。

随后将间隔提示移至中间，并让体重靠左、背甲内容靠右，使三部分视觉对称，消除背甲后方留白；保留整条记录宽度，默认展示最新记录。完成36组布局/交互及8项日期语义检查，卡片高度保持不变；包括从间隔文字起手拖动、取消删除、同日与跨日、建档参照和缺失日期。结果为 `output/ui-consistency/growth-interval-layout.json`。该位置调整仅重跑定向检查，未再次重跑上述880场景。
