# 全软件检查与优化（2026-10-24）

目标平台为苹果、安卓 App，电脑用于预览测试。本轮先检查全软件页面与关键数据操作，再修改有明确依据的问题；延续此前确认的商品 7 天提醒、30 天未确认下架规则，以及手机端龟友圈调整。

## 本轮实际修改

| 问题 | 现在的处理 |
| --- | --- |
| 搜索、登录、评论、互动消息及部分管理请求没有超时，弱网时可能一直等待 | JSON 请求统一有截止时间：既有列表／聊天／天气／会话检查 15 秒、账号同步 20 秒，其他请求 30 秒；图片 JSON 上传单独保留 120 秒。请求和响应正文读取共用截止时间，结束后释放忙碌状态。请求层不自动重放超时的提交 |
| HTTP 200 的异常 HTML、损坏 JSON、null 或数组会被当成空对象成功返回 | 返回明确的异常响应错误，不再将这些返回视作成功；保留旧版合法 JSON 对象、HTTP 错误状态与匹配账号的 401 会话失效处理 |
| 评论已写入服务器，但手机没收到回执，重试可能重复发布 | 手机详情页对同一会话、帖子、正文和回复对象保留提交编号；服务器按帖子和真实作者去重。失败保留草稿及编号，明确成功后清除；重试不重复产生通知。旧客户端不传编号仍兼容 |
| 新增“确认在售”操作未纳入通用重复点击保护 | 补入通用请求反馈与点击保护名单，保留按钮原状态和原业务规则 |
| 社区手机布局改为窄列后，固定搜索条仍沿用较宽容器 | 搜索条与社区内容采用相同的 480px 最大宽度，保持居中、贴合标题栏和滚动固定效果 |
| 登录／注册缺少系统自动填充语义 | 手机号使用电话输入类型与用户名提示；区分当前密码、新密码，验证码补充一次性验证码提示。未改动登录、协议确认或密码规则 |
| 部分页面的停留统计归属错误 | 补齐 `marketMy`（我的商品）、`communityActivity`（互动消息），搜索页按商品／社区来源归属。保留服务器兼容的“壳友圈”内部统计名称，不回填历史数据 |
| 更新后的静态资源可能沿用旧缓存标识 | 更新本轮 App 主脚本、通用交互、社区脚本与样式引用版本，并重新生成 `www` |

超时或异常回执表示客户端尚未确认结果，并不表示服务器已回滚。评论去重需要本轮服务端和新版 App 配合；本会话中的原样重试可以复用编号，关闭应用后不承诺恢复该内存编号。

## 检查覆盖与结果

所有账号与记录均为合成数据。HTTP 工作流启动隔离的本地服务，浏览器请求被拦截，没有对线上用户发帖、发送私信或推送。

| 检查 | 结果 |
| --- | --- |
| 全页面首轮源码检查 | 50 个页面、738 个布局／状态／弹窗／网络场景通过 |
| 最终 App 资源检查 | 加载最新 `www`，苹果与安卓模拟环境各 738 场景，共 1,476 场景，零失败；安卓使用本项目共享代码适配和平台样式 |
| 手机龟友圈交互与布局 | 两端各 15 组交互、40 个布局；包括丢失回执后的去重重试、评论定位、草稿、权限、图片、窄屏与深色主题 |
| 通用交互 | 31 项通过，包括损坏成功回执、重复点击、忙碌状态清理、弹窗焦点及背景交互管理 |
| 请求异常专项 | 23 种结果通过，包含截止时间、响应正文卡住、错误格式、HTTP 状态、旧协议、账号归属及反馈清理 |
| API 工作流 | legacy 存储与 records 测试驱动均通过；额外覆盖同编号并发评论、通知去重及作者隔离 |
| 搜索 | 固定搜索栏宽度、搜索历史、中文输入法、失败回退、迟到结果隔离、结果详情返回通过 |
| 数据可靠性 | 本地离线保留、双浏览器同步与恢复、账号切换、客户端写入竞态、备份恢复与备份存储通过 |
| 日常关键操作 | 照片选择及取消／竞态、档案照片分页、批次账本选择、成长提醒取消、繁殖／龟池等核心业务校验通过 |
| 登录与消息 | 找回密码 UI／服务端、通知分页和精确已读、推送打开与账号隔离、安卓推送客户端检查通过 |
| 商品 | 搜索交互、此前确认的商品在售规则及手机界面检查通过 |
| 源码与产物 | JS 语法、`git diff --check`、本轮静态资源与 `www` 的哈希一致性检查通过 |

检查同时发现三个旧回归测试环境缺少后来新增的发布版本、会话版本和会话状态依赖；已补全测试环境并恢复原有断言。此项是测试修复，不作为线上软件故障计数。

## 交付边界

完成了共享源代码、隔离验证和 `www` 构建，尚未部署生产服务、同步原生工程或发布 IPA/APK。当前工作树还包含此前用户已确认的商品规则与社区改动，正式发布需一起审查对应依赖；旧网页专用安装器不包含本轮 App 功能。

这里的苹果、安卓检查都在 Windows Chrome 中通过原生桥模拟执行，不能代替 iOS WebKit、Android WebView 真机、系统键盘／自动填充和商店安装包验收。本轮没有调整版本强制更新门槛、通知发送频率或管理员权限。
