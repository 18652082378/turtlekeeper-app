# iOS 1.1.8（136）与安卓 1.1.8（27）

2026-10-18。共享页面同步更新，苹果主应用和通知扩展的 Debug/Release 四处构建号统一为136；安卓 versionCode 独立递增至27。版本名保持1.1.8，最低可用版本策略保持原配置。

## 本次改动

- 龟友圈新增成长报告分享入口、可编辑发帖提纲、个人品种快捷搜索和已加载内容中的待回复筛选。分享前可以编辑，档案实拍由用户选择加入。
- 龟集市首页增加品种快捷查找、收藏与发布入口，直接提供排序、价格、区域和交付筛选；返回列表保留图片与浏览位置。
- 加固发帖草稿、相册、上传重试与账号会话隔离；发布失败保留原草稿，后台发布完成保留其他页面尚未提交的输入，拒绝覆盖新帖的过时刷新和分页响应。
- 包含发布商品表单窄屏宽度、提醒星期按钮与取消按钮的布局修复，以及账本工具栏检查定位修复。保留原有档案默认品种照片、随机系统头像和已确认的破壳小龟插画。

详细实现与测试边界见 `docs/discovery-engagement-20261018.md` 和 `docs/additional-ui-audit-20261018.md`。

## 上传代码与云端构建

在项目目录的 Git Bash 执行：

```bash
bash scripts/upload-ios-136.sh
```

只检查而不提交或推送：

```bash
bash scripts/upload-ios-136.sh --check
```

脚本只提交发布清单中的源文件，先检查资源与版本，再推送main；核对远端提交一致后才提示上传完成。随后在Codemagic新建构建，选择main最新提交与 iOS TestFlight 流程。不要重试绑定旧提交的历史任务。检查云端日志为1.1.8（136），成功后在App Store Connect查看该构建。

源码包使用 `node scripts/package-ios-source.cjs` 生成，附逐文件SHA-256清单及ZIP校验值，包含两端原生工程与共享源文件，不包含私钥、环境凭据、依赖缓存、用户数据和原生构建产物。安卓仍需使用正式签名及本机安全保存的推送配置生成APK。
