# 返回、滚动与键盘检查（2026-09-25）

## 范围

检查 app.js 的页面路由、DOM/HTML 返回缓存、侧滑动画、底部导航、下拉刷新、壳友圈和龟集市分页、键盘视口处理，以及档案选择、图片预览、客服和交易指南弹层的交互。查看 Android 返回键及原生键盘事件接入、iOS 容器相关代码。

浏览器自动化覆盖当前路由表全部 49 个页面的基础渲染、返回原页面、恢复纵向滚动位置及固定导航位置。详情页面采用本地模拟档案/帖子/商品。该覆盖不等于所有页面的全部业务操作或所有设备验证；线上用户数据未被访问或修改。

## 确认并修复的问题

| 问题 | 触发及表现 | 修复 |
| --- | --- | --- |
| 连续返回的旧动画干扰 | 侧滑松手后、动画结束前再返回，旧回调再退一层；上一轮返回的延迟帧会删除下一次侧滑预览 | 普通返回先取消未完成手势；延迟帧只清理自己持有的预览，不再重置新手势的 transform |
| 原页重绘留下临时定位 | 手指侧滑过程中发生数据重绘，持久导航仍处于绝对定位 | 重绘之前恢复当前手势的固定层并取消其后续动画 |
| 壳友圈返回后分页失效 | 从详情返回缓存页面，只重建了龟集市滚动观察器，壳友圈不再加载下一页 | DOM 恢复及 HTML 回退均重新接入壳友圈分页观察器 |
| 键盘误判 | 无软键盘但输入仍聚焦时隐藏导航；Android 已通知键盘关闭却未采用；页面缩放被当成键盘并抬高回复栏 | 使用视口变化和原生键盘状态判断；排除缩放、只读及非文本输入；旋转后重置尺寸基准；重绘恢复输入焦点后再同步状态 |
| 下拉刷新中断后不复位 | 切页、失焦或改为多指操作后仍保留拖动状态和提示 | 页面跳转及生命周期事件统一取消；多指操作立即取消；正在执行的请求仍由原任务完成清理 |
| 内部滚动误触下拉刷新 | 主页面位于顶部时滚动内部列表，也启动背后的页面刷新 | 有自身纵向滚动区域的控件保留其手势 |
| 弹窗误触页面返回 | 在客服等 body 级弹窗上侧滑，底层页面发生返回而弹窗还在 | 页面手势仅接收 app 内、非对话框/遮罩区域的操作 |

初始回归中 12 个针对性断言均可复现失败，记录在 `output/navigation-lifecycle-before.json`。随后补充了连续侧滑、旋转、正常下拉刷新以及重绘时保留输入的验证。

## 验证与结果

- `scripts/test-navigation-lifecycle.cjs`：16 个交互场景，加全部 49 个路由的基础检查；结果为 `output/navigation-lifecycle.json` 与 `output/navigation-pages.json`。
- `scripts/test-bottom-nav-recovery.cjs`：三个屏幕尺寸、33 个原导航问题场景。
- `scripts/test-edge-preview-layout.js`：明暗主题、实际指针侧滑、固定层位置、原 DOM、正常完成及回弹。
- `scripts/test-market-back-scroll.js`：滚动位置、筛选、分页缓存及返回方式。
- `scripts/test-navigation-freshness.cjs`：返回后显示最新数据，及紧接返回后的第二次修改。
- `scripts/test-reply-dock.js`、`scripts/test-comment-layout.js`：回复栏键盘几何及评论布局。
- `scripts/test-message-cache-ui.cjs`、`scripts/test-module-loading.cjs`：离线/延迟数据与页面缓存。
- `scripts/test-archive-photo-picker.cjs`、`scripts/test-trade-guide.js`：选择弹窗、关闭清理、交易指南及前后台恢复。
- `scripts/test-market-return-updates.js`：保留商品媒体节点、更新状态及公告。

以上使用本地资源与模拟数据进行浏览器测试。未执行 iOS/Android 真机或系统软键盘自动化；不能据此保证所有系统版本都不存在其他缺陷。修复仅在本地源代码和构建产物中，未发布正式版。
