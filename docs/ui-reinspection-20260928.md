# 全页面与共享 UI 复查（2026-09-28）

本轮仅检查和修改本地工作区。所有浏览器资源直接由工作区文件提供，API 返回测试响应，外部域名请求阻断。使用虚构档案、虚构账号标记和合成记录，没有接触正式私有账号或修改正式数据，没有部署、修改版本号或调整已认可的成长卡片布局。

## 发现及修复

| 问题 | 复现与修复 | 证据 |
|---|---|---|
| 成长卡片可获得键盘焦点，但回车和空格无法打开档案 | 实际卡片用键盘操作得到两个失败用例；共享模块为具有按钮语义的非原生控件补足键盘激活，同时跳过已有处理、内部输入控件和原生按钮 | `output/ui-experience-keyboard-red.json`；新增 Enter、Space、内部删除取消三项实际交互回归 |
| 原生校验提示进入包裹标签，改变字段名称并挤压协议勾选内容 | 实际注册表单执行校验可复现；提示移到包裹标签之后，仍以 `aria-describedby` 关联；输入后只清除对应字段错误 | `output/ui-experience-validation-red.json`；新增注册校验标签回归 |
| 校验状态被旧主题样式覆盖 | 深色错误提示变成普通灰色，字段边框无错误区别；提高错误状态规则优先级，并整理表单/验证码行错误提示位置 | 附加检查的注册错误表单前后截图 |
| 320px 验证码输入框过窄 | 验证码所在行与标签内部各分成两列，层层压缩；移动端验证码标签改为纵向，操作按钮保持同一行 | `output/ui-review-additional/before` 与 `after` |
| 连续英文长文本被页面裁切 | 帖子和商品说明允许长单词换行；公告网格限制最小列宽，标题和正文换行；较长表单标签也允许换行 | 附加检查的帖子、商品、公告截图 |
| 集市加载失败提示只占商品网格半列 | 人工查看错误页截图发现，页面宽度断言本身无法发现；空态和失败提示现在跨完整网格，重试按钮使用统一控件样式 | `output/ui-review-additional/before/market-error-dark-390.png` 与最新矩阵截图 |
| 注销确认勾选框被公共 label 网格规则撑满一整行 | 人工查看弹窗截图发现；仅恢复确认行的横向标签布局，保留原有必选、密码与禁止提前提交逻辑，并统一弹窗可见焦点 | `output/ui-review-additional/before/modal-account-delete-teal-390.png` 与最新矩阵截图 |

纯 CSS 修正以实际截图和现有全页面矩阵复核，没有新增照抄实现的样式测试。共享行为新增四项用户操作回归，原 24 项现在合计 28 项。

## 检查程序本身的覆盖缺口

旧静态矩阵的集市、社区、消息错误场景只注入错误字段，但配置仍为离线模式，页面未显示对应错误。新增状态内容断言后先得到三个失败结果（`output/ui-consistency/state-coverage-red.json`），再通过独立合成云配置正确渲染并验证错误状态。消息空态同步清空聊天缓存，避免从缓存重新合成好友条目。账本新增/编辑状态的截图现在定位到真实表单。

静态错误状态用于外观检查。另有 16 个场景实际延迟浏览器请求、返回模拟 503、点击重新加载并恢复合成内容，两种验证方式不能互相替代。

## 本地结果与产物

- 全页面矩阵：49 个路由、93 个页面/表单/状态，320/390/430/1280px，浅色与深色；加选择器、14 类弹窗及模拟请求，共 **880 场景通过**。无运行异常、文档横向溢出、底栏越界或缺少名称的可见字段/操作控件。
- 共享交互：**28 项通过**，包括新增的成长卡片键盘操作、嵌套删除取消和实际注册校验标签检查；现有弹窗焦点、恢复、隐藏/重开、忙碌状态、防重复提交、失败解除、媒体关闭防穿透继续通过。
- 独立附加检查：**14 场景通过**，320px 浅/深色分别覆盖错误注册表单、长繁殖/账本文本、500 只关联龟、长帖子/商品/公告。没有浏览器异常或元素超出页面。人工查看代表性表单、长文本、500 只摘要、失败页、选择器及注销弹窗截图，不只依赖几何结果。
- 最新矩阵报告与可筛选截图：`output/ui-consistency/report.json`、`report.md`、`index.html`。
- 共享交互结果：`output/ui-experience-regression.json`。
- 一次性附加检查脚本及前后证据：`output/ui-review-additional.cjs`、`output/ui-review-additional/before`、`output/ui-review-additional/after`。这些脚本仅使用合成数据。

## 尚未验证

没有在真实 iPhone/WebView 上验证系统键盘、安全区、实际侧滑和前后台切换。没有执行支付、系统相册/相机、通知权限或原生分享操作，也没有做完整屏幕阅读器与颜色对比度认证。团队页面在此矩阵中仍是访客功能预览。独立业务/团队 API 测试由对应专项报告说明；本报告不将其合并成生产环境验证。

本地工作区修复尚不等于 App Store 正式客户端已修复。
