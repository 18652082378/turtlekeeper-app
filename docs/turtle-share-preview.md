# 乌龟档案分享

分享标题为“龟友手账”，说明为昵称、品种、已知性别及已记录的体重、背甲长度。缩略图使用所分享乌龟的照片。照片为本地内嵌图片且已登录云端时，先通过现有图片接口生成公开图片地址；上传失败则停止本次分享，不发送缺少预期照片的链接。

链接继续使用原有 `?turtle=` 格式，旧链接兼容。服务端为链接输出 Open Graph、Twitter 及 image_src 预览信息，普通网站和商品分享入口保持原有行为。分享不读取账号数据库，也不增加分享数据库。

公开详情页省略未填写的字段，不展示来源、购入价和龟池。空的成长快照字段与无数据的成长区域也不展示。主人自己的档案详情和金额记录保留原有行为。

iOS 的 TurtleMediaPicker 增加 shareLink，提供链接、标题、说明及照片给系统分享面板。照片下载最多 4 MiB，超时或失败退回链接分享；缩略图通过 ImageIO 缩至 256 像素。链接取消后不自动复制或再次分享。

## 验证与发布范围

- `node scripts/test-turtle-share-server.cjs`：真实静态 HTTP 响应、预览元数据、安全转义、无数据库副作用、商品及普通页面兼容。
- `node scripts/test-turtle-share-ui.cjs`：网页/原生桥接分享参数、公开字段与空字段、翻页布局、取消与复制兼容、内嵌图片上传及失败、超长成长记录。
- 配合 MOBILE_UI_PLATFORM 和 BROWSER_ENGINE，分别验证已打包 iOS/WebKit 和安卓/Chromium 页面；`--local-preview` 验证用户实际使用的 file:// 本地入口。

服务端预览需部署修改后的 server/server.js；公开页面的空字段优化需部署网页资源；原生 iOS 分享面板改动需重新构建并安装 App。Windows 中的页面及资源检查不等于 Xcode 编译或真实微信接收结果验证。微信最终采用哪些预览数据由其客户端决定，需在新 App 和服务端均更新后实机验收。
