# 全模块细节检查与修复

检查覆盖看板、档案、成长记录、账本、繁殖、龟池、养护、提醒、集市、龟友圈、私信、搜索、反馈、账号及管理页面，使用合成账号和本机隔离服务。

## 确认并修复

1. 草稿图片保存失败后，即使空间恢复，相同内容会被“无变化”判断跳过。新增“重试保存”，无需重新输入或重选图片；成功后收起重试入口，失败时明确区分已保存的文字与未保存的媒体。数据库首次打开失败后允许重新打开。
2. 草稿清理依赖包装网络函数，网络适配器替换后可能再次恢复已经发布的内容。改由帖子和商品发布流程在确认成功后通知草稿模块；只清理对应提交版本，不清理后来修改的草稿。
3. 部分评价、反馈等操作缺少账号切换后迟到响应的防护。JSON 请求统一记住发起账号与会话，身份变化后拒绝旧结果，避免旧响应进入新账号；未登录的登录流程保持原有行为。
4. 商品封面和媒体上传缺少完整的发起账号绑定。在每个上传阶段及正式发布前复核账号，所有文件上传使用发起会话，切换身份后停止后续请求。
5. 商品后台发布完成会把正在填写反馈等表单的用户拉回集市。现在更新商品数据时保留当前页面、原表单节点和未保存文字；重新打开的商品编辑器也不被旧任务清空。
6. 手势返回预览会复制视频和嵌入页面节点，可能引发多余媒体加载。预览仅保留静态展示，移除克隆中的播放器和 iframe，原页面节点保留。
7. 看板品种、龟池和排序控件在小屏时截断默认文字。调整控件内边距；300px 及以下安卓布局改为两列筛选，后续控件跨行，保证文字与箭头有空间；常规手机保留原有一行结构。
