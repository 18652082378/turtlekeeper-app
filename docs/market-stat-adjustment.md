# 单条商品计数调整

2026-10-02。用户要求将“果核大尾种公”（¥3899，龟仙人）的曝光设为 134 次，显示 1 人想要。只读正式接口核对商品 ID 为 ff2e7d9f-e236-40c9-9b2d-a8392f848cb8，核对时曝光 5、浏览 26、想要 0；这些统计仍会随真实活动变化。

本次补丁只匹配该 ID，同时校验标题和价格。手动想要调整记录在该商品的 manualMetricAdjustment，包含固定操作号、调整时间、来源、原曝光及 wantDelta。真实 wantedPhones 保留，不为任何账号添加收藏，也不修改平台每日曝光、浏览、想要事件统计。所有商品默认仍使用真实计数，列表、详情、聊天商品快照、曝光/浏览/想要响应和管理员商品统计均采用同一计数函数。之后真实曝光及想要继续累加。

补丁不修改客户端，不需要新增 iOS 构建号。脚本 --check 读取并校验代码、进程及数据；--apply 先备份代码，停止 API 后重新读取权威存储并备份数据，安装计数函数及单条调整，重启并检查原版本策略和该商品详情。支持 JSON、MySQL legacy 和 records；records 使用已有模块的写入锁和增量事务，不执行迁移。普通每日统计、浏览、其他商品及账号数据保留。已有同操作号时重复执行不会重置后续增长；未知函数、错误商品、其他人工调整、曝光超过 134 或真实想要超过 1 时拒绝修改。

失败时停止 API，再移除本次单条调整和恢复代码；恢复曝光时保留重启后发生的真实增长，保留新浏览与真实想要。出现未知并发代码或数据时拒绝覆盖并报告备份位置。备份在 server/backups/market-stat-*，目录 0700、文件 0600；包含私有数据，仅保存在服务器。

本地 test-market-stat-adjustment.cjs 已覆盖单条匹配、不影响其他数据、真实意向记录、后续增长、重复执行、未知代码拒绝、命令 SHA256、JSON 写入/备份、预检不写入、失败保存恢复、健康失败回滚；MySQL 两种适配通过隔离的事务模拟验证，分记录模式只更新目标 SQL 行。另用临时目录的真实本地 HTTP API 验证详情、列表、曝光、浏览、想要及重复想要。原有 API 流程和城市补丁回归通过。尚未在正式服务器执行此调整；正式 MySQL 与真机显示未验证。

本地 Git Bash 执行 `node scripts/copy-market-stat-server-command.cjs --clipboard`，到已登录的服务器终端粘贴执行。命令内嵌完整脚本并校验 SHA256，无需公网 IP 或手动上传；会短暂重启 API。看到 SUCCESS 后关闭并重新进入商品详情获取新统计。
