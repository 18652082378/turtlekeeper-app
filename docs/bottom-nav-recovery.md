# 底部导航偶发停在页面中间

## 已确认原因

侧滑返回会临时将固定层（含底部导航）改为绝对定位，让它随页面移动。
旧代码在松手时清空拖动对象，但恢复定位仍由动画结束回调负责。
若此时再次触摸、窗口失焦或页面进入后台，清理函数会取消该回调，却找不到需要恢复的固定层。
底部导航节点在页面间复用，因此临时绝对定位被带到龟集市，随页面滚动停在屏幕中间。

在本地实际页面复现：402 × 874 视口，侧滑松手后立即再次触摸，随后进入龟集市并滚动 480 px。
修复前导航为 `position: absolute`，屏幕坐标 top 316、bottom 394；修复后为 `position: fixed`，top 796、bottom 874。
这是能够产生用户截图现象的一条确定代码路径；未获得受影响设备型号，尚未在客户设备确认。

## 修复

- 单独保留侧滑结束动画的固定层恢复信息，正常结束与中断均恢复原样式。
- 新触摸、失焦、页面隐藏/显示、可见性变化、窗口尺寸变化及前台恢复都执行清理。
- 普通页面跳转在保存快照之前结束手势，防止临时坐标进入缓存 HTML。
- 已脱离文档的节点也恢复样式，避免重新挂载旧页面时带回错误定位。
