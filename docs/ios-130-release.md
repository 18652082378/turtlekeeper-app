# iOS 1.1.6（130）温度提醒界面修复

日期：2026-10-07。版本号保持 1.1.6，主应用、通知扩展和网页构建号统一为 130。

提醒日期增加「当天」（advanceDays=0），与提前1～7天一起共8个选项；默认仍为提前1天。选择当天会在设置时间检查北京时间今天的最低气温，规则和通知使用「当天／今天」，保存、重新读取及重启不会回退为提前1天。

删除温度提醒页顶部的重复介绍卡，保留日常养护导航和温度提醒标签。重新分组地点和提醒条件，统一输入框、时间控件、下拉框的宽度、高度、标签和间距；重新读取设置移到表单底部。

地点使用说明移到搜索框前面。首次使用时，未勾选说明就搜索、定位或开启后保存，会滚动并聚焦到对应复选框，以边框和旁边的文字提示说明下一步。不会自动勾选或发送地点，不会丢失用户已填写的城市、温度、时间。用户勾选后立即清除提示；未选择地点就保存会引导到搜索框。

cd /c/Users/Administrator/Documents/Codex/2026-06-02/apple-store/outputs/turtlekeeper-app
