# 安卓原生边界检查（2026-10-15）

本次在安卓1.1.8（20）修复原生能力与页面衔接问题。保留19号包的固定导航、正常滚动和下拉刷新。未操作生产服务器、账号、支付或推送凭据；苹果版本号仍为1.1.8（134）。

## 确认并修复的问题

| 范围 | 发现 | 修复 |
| --- | --- | --- |
| 定位权限 | 安装包缺少前台定位权限；页面只接受精确位置授权 | 声明前台精确/大致位置权限，接受大致位置；拒绝后的设置指引区分安卓和苹果 |
| 国内安卓定位 | 原安卓定位插件依赖Google定位服务 | 安卓改用系统LocationManager，苹果保留原插件；请求超时或应用进入后台后注销定位监听，不申请后台定位 |
| 聊天拍照/录像 | 精确MIME列表无法触发Capacitor安卓的相机分支；Android 11以上缺少相机应用可见性声明 | 仅安卓打包时改为image/*、video/*；补充拍照/录像intent查询，不申请全量应用查询权限。保留苹果原有格式列表 |
| CSV/备份导出 | 安卓WebView走Blob下载链接，不能确认是否落盘 | 调用系统“另存为”，写入完成才报成功；取消、无效位置、写入失败明确反馈，不申请存储权限 |
| 成长卡/团队档案图片 | 安卓依赖浏览器图片下载，并可能提前提示已保存 | 成长卡保存走系统“另存为”；图片分享走原生分享窗口和临时只读content URI。打开分享窗口不宣称已经发送或保存 |
| 键盘与系统返回 | JS返回处理可能先关闭页面或取消草稿 | 收到原生键盘可见状态时，先关闭键盘，保留页面和输入；后续返回继续走原导航栈 |
| 视频缓存入口 | 安卓展示仅在iOS实现的专用视频缓存设置，并尝试调用不存在的原生插件 | 安卓不展示该入口、不调用iOS缓存插件；视频继续通过原网络播放路径加载 |

## 已验证范围

18项原生测试全部通过，其中10项覆盖本次新增的原生边界行为。正式签名APK已生成，构建和Android Lint发布检查通过；包内223项资源与当前构建输入逐项匹配，前台定位权限与相机intent查询已在成品清单中核实。成品信息见[20号版本记录](android-118-20-release.md)。

- 双端打包资源一致性、苹果本地插件保留；安卓专用代码不注入苹果入口。
- 安卓2400项、苹果800项页面布局检查；窄屏、普通手机、折叠宽度及明暗主题检查。
- 36组可信触摸手势检查：正常滚动、顶/底部下拉、释放、刷新与固定导航。
- 客户端回归：安卓大致位置、拒绝权限、苹果权限语义，图片保存取消/失败、分享不虚报成功，安卓拍照/录像MIME适配。
- 原生Robolectric测试：实际Activity生命周期、系统栏与WebView策略，文档选择Intent、UTF-8写入和结果、取消与无效目标、重复导出防护、图片校验、分享Intent的URI读授权；系统定位缓存、权限、超时和后台取消。
- 同步与备份操作、温度提醒设置错误恢复、支付会员与苹果订阅隔离回归。

测试不会调用生产支付、发送真实通知或修改线上数据。图片分享测试在Windows上仅替代URI创建，因为AndroidX FileProvider的路径匹配以安卓Unix路径为前提；图片校验、文件写入、分享窗口Intent、读授权和返回值仍由实际插件处理。该测试不能证明微信等接收应用已成功读取图片。

## 真机验收尚未完成

本机没有连接安卓设备。浏览器视口模拟与Robolectric均不等于厂商系统验收。上线前需使用实际手机确认：

1. 只授予“大致位置”、拒绝授权、关闭定位服务后的反馈，重新开启后的定位。
2. 拍照/录像、取消拍摄、照片/视频选择及回到聊天后的内容。
3. CSV和完整备份另存为，检查实际文件内容；取消保存、空间不足或目录不可写时不虚报成功。
4. 成长卡保存和微信等应用接收图片；系统分享取消时不提示“已发送”。
5. 输入法弹出后按返回、折叠/展开、前后台切换及导航固定。
6. 通知允许/拒绝、后台/杀进程投递和点击路由；支付宝安装/未安装、取消支付和支付后回跳。

厂商推送通道尚需独立配置和真机验证；本轮不将现有阿里云推送配置描述为所有厂商杀进程后均可送达。
