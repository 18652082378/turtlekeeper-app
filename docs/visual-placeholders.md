# 无图占位和空页面优化（2026-10-18）

采用统一的本地SVG图案，保留已经确认的破壳幼龟PNG。小封面使用简洁图案，空页面使用更大的场景图案、说明和操作入口。图案不依赖网络和图片SDK。

- 龟池：苗池、压成池、种龟池使用不同的小龟组合；未知旧类型使用通用龟池图，不猜测实际类型。
- 账本：无照片的龟粮、耗材/设备、药品/看病/检测、水电、运输、其他支出分别使用相应图案；有上传照片时继续优先显示照片。表单的“照片”文字占位替换为图案。
- 默认头像：空间与卖家默认头像改为圆嘴小龟；保留用户自己的头像。社区姓名首字头像保持原有辨识方式。
- 默认档案照片：原简单圆形拼接小龟改为有表情、背甲与四肢的圆润小龟；品种实拍资源不变，不迁移或覆盖已有照片数据。
- 空页面：龟池、成长、繁殖、账本补充对应图案和新增/选择档案入口。入口只打开页面或草稿，不直接建立业务记录。
- 集市：无商品与搜索无结果分别使用店铺和搜索图案，保留原有发布和清除筛选操作。登录、加载、错误等状态分支不变。
- 筛选：有账目但因日期或分类被筛掉时提示“没有符合筛选的账目”，与账号真正没有账目区分。
