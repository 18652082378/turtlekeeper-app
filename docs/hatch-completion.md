# 孵化完成与团队入口合并 · 1.0.9（111）

- 繁殖详情底部两个按钮：左侧“孵化完成”，右侧“确认孵化”。右侧仍按本次数量创建幼龟并关联看板，分批出壳不会自动结束窝次。
- “孵化完成”只保存完成状态及详情修改，不新增幼龟。若填有本次出壳数量，先提示保存该批次，避免漏计。
- 已完成窝次在个人繁殖列表右下角显示“✓ 孵化完成”。详情可“重新开启孵化”；关闭期间不能新增出壳，历史补关联仍可用。
- 主账号和团队共用 `breedingRecords[].incubationClosed`。只有严格为 true 才计入“已结束 · 最终孵化率”；未标记记录均为进行中，包括历史记录和出壳数达到受精数的记录。最终孵化率仍按已完成窝次的总出壳数 / 总受精数计算，分母为零时显示待完善。
- 团队原“繁殖”“孵化”读取同一组数据，统一保留“孵化”。保留两边原有的照片、备注、出壳批次、对比、筛选、新增编辑功能及权限。

## 部署

`output/turtlekeeper-hatch-completion-v12.tar.gz` 包含 v11 单设备登录与消息缓存修复，无需先装 v11。上传到服务器 `/tmp/` 后执行：

```bash
cd /tmp &&
tar -xzf turtlekeeper-hatch-completion-v12.tar.gz &&
node /tmp/turtlekeeper-hatch-completion-v12/deploy.cjs --check &&
node /tmp/turtlekeeper-hatch-completion-v12/deploy.cjs --apply
```

会核对已审阅的代码版本、备份代码并做健康检查，失败回滚。版本不匹配时停止，不要强制覆盖。不会覆盖数据库、上传文件或 `.env`。

手机端需重新上传 Git 并构建安装包含本次修改的 1.0.9（111）。尚未部署到生产服务器或完成两台实机测试。
