# 龟集市搜索意外导航修复

2026-10-02。用户反馈点击顶部搜索框、输入品种时偶发离开龟集市，目标页面可能为看板。正式客户端的确切触发条件尚未捕获。

## 本地复现与修复

隔离浏览器测试中，将触摸起点设为搜索框，模拟键盘/布局变化后后续 click 落到固定底部导航。修复前会切换到 home 或 messages；修复后阻止该次无关导航。新的独立导航触摸及键盘/辅助功能点击仍然允许。

另一次回归在中文组合输入期间调用保留输入值的后台刷新：修复前搜索输入节点被替换，修复后保留同一个编辑节点，刷新在编辑结束后显示。品种建议防止触摸默认动作提前移走焦点，提交处理拒绝未完成的中文组合输入，解绑后的旧表单不会改变其他页面状态。

## 已验证

- scripts/test-market-search-interactions.cjs：Chromium、桌面 WebKit 各 14 项通过，覆盖输入、模拟键盘尺寸变化、触摸起点/点击落点不一致、正常导航、品种建议、组合输入、延迟刷新、长按期间刷新、重复绑定及旧表单事件。
- scripts/test-navigation-lifecycle.cjs 和 scripts/test-navigation-freshness.cjs：两个浏览器引擎的既有返回、短边缘手势、页面恢复和返回后数据展示回归通过。
- 测试拦截网络请求，只使用隔离的虚拟账号与商品，不访问正式接口、不更改正式数据。

修复前复现记录在本地 output/market-search-before.json；修复后报告为 output/market-search-regression.json 和 output/market-search-regression-webkit.json。报告属于本地构建产物，不加入源码提交。

## 未验证与真机验收

桌面 WebKit 并非 iPhone。原生键盘、中文候选字确认、系统键盘搜索按钮和布局变化使用模拟事件；本次未验证正式环境或真实设备上的原始故障。

安装 1.1.3（122）后，在龟集市依次输入拼音并选择中文候选、点品种建议、点键盘搜索、收起键盘，再主动点击看板；搜索过程应停留在龟集市，主动导航应成功。输入时等待商品后台刷新并多次收起/展开键盘，检查文字和焦点稳定，再从商品详情执行短边缘返回。记录实际设备、系统版本、触发步骤和结果。

这是客户端修复，保持当前 1.1.3（122）版本，尚未上传，无需为此部署服务器。
