# 发布与浏览体验优化

本次在现有 1.1.9 源码上完成三项优化，尚未代表线上部署或新的 App Store 安装包。

- 私信列表上下滑动可收起键盘，草稿和光标按账号、登录会话及聊天对象保留。横向手势、输入框选字、弹窗和多指操作不会触发。发送、删除、清空会话后的旧草稿不会自动回来。
- 龟集市与龟友圈后台发现新内容后显示可点击提示，已有卡片和阅读位置保留；点击后才采用对应的新列表、排序会话和分页位置。主动刷新仍立即更新；切换账号、筛选或收到更新的完整响应时会清理过期提示。
- 龟友圈发帖和龟集市发布出售自动保存本机草稿。文字、发布选项及已选图片/视频按账号保存；新增出售和编辑不同商品分别存储。刷新、返回或上传失败后可恢复，成功发布后清理对应草稿，也可手动清除。图片以原始字节写入 IndexedDB，文字另有小型本机存储后备；存储失败会明确提示，不把未保存的图片显示为保存成功。

草稿仅保存在当前设备/浏览器，清除浏览器数据会删除草稿。不同设备不会同步。没有修改用户云端档案、成交数据及版本更新策略。

验证入口：`test-community-chat-keyboard-ui.cjs`、`test-feed-updates-ui.cjs`、`test-publishing-drafts.cjs`。覆盖 Chromium/WebKit、账号与会话隔离、光标与滚动位置、完整媒体恢复、发布失败/成功和过期响应；真机键盘行为仍需安装包验证。
