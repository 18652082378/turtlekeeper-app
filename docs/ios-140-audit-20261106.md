# 1.2.0（140）复查记录

本轮从本机与 Codemagic 环境差异、模块间数据关联、实际操作和发布检查覆盖范围重新复查。浏览器使用项目锁定版本对应的 Chromium 和 WebKit，所有接口操作使用本机隔离服务与合成账号。

## 发现并修复

- 上传前原先只跑 iOS 定向检查，遗漏了云端安卓检查。上传脚本现执行完整的两端检查，再进入 Git 上传步骤。
- 返回、聊天和常用模块检查原先在部分平台下读取网页源码，现按目标平台读取实际打包目录。浏览器测试统一使用配套引擎，移除了指定本机 Edge 或 Chrome 的要求。
- 繁殖列表中的名称、日期，以及成长图表中的日期存在未转义的拼接。合成输入复现了事件属性被执行的问题，现将这些内容作为文字显示，并覆盖繁殖编辑表单的日期和数量属性。
- 离线冷启动的读取尚未结束时恢复网络，原逻辑会跳过正在进行的读取，使待同步记录等待下一次轮询。现合并同一会话的读取任务，联网时等待旧任务并在失败后重试一次；切换账号后旧任务不能迁移新账号照片或清除新任务状态。
- 私聊发送按钮在“发送中”状态固定宽度后，280 像素极窄屏仍会挤压输入框。现按屏幕宽度使用稳定的按钮尺寸，发送前后保持位置，输入框和表情入口均通过两端检查。
- 数据检查中存在过期版本断言、已撤出功能的残留依赖、隔离服务漏带城市数据文件的问题。已更新对应夹具，离线检查统一保留本地静态页面并中断全部 API 请求，验证离线重启后内容和待同步记录继续保留。
- 延续上一轮对价格遮罩位置、聊天发送中按钮宽度和云端浏览器选择的修复，并扩大上传前检查范围。
